# Pinned to versions confirmed working with this codebase's PaddleOCR 3.x API
# (use_textline_orientation, .predict()).
# If you must use different versions, re-check ocr/paddleocr_pipeline.py against
# your installed paddleocr's actual API -- 2.x and 3.x are NOT compatible.
#
# paddlepaddle IMPORTANT: pinned to 3.2.2, not the newer 3.3.x line.
# PaddlePaddle 3.3.0/3.3.1 has a confirmed upstream CPU bug where MKL-DNN
# (oneDNN) crashes with "NotImplementedError: ConvertPirAttribute2RuntimeAttribute
# not support [pir::ArrayAttribute<...>]" (Paddle GitHub issue #77340). The only
# way to avoid the crash on 3.3.x is enable_mkldnn=False, but that disables CPU
# acceleration entirely and makes OCR ~30-40x slower (minutes -> hours for a few
# hundred images). 3.2.2 doesn't have the bug, so MKL-DNN stays on and OCR runs
# at normal speed. Do not upgrade past 3.2.x without re-testing this.
